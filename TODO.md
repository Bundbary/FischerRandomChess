# Fischer Random Chess - Future Enhancements

## Quick Wins
- [ ] **Rematch button** - After game ends, challenge same opponent again
- [ ] **Captured pieces display** - Show taken pieces beside the board
- [ ] **Sound effects** - Move, capture, check, game over sounds
- [ ] **Board flip button** - View from opponent's perspective

## Medium Effort
- [ ] **Clock/Timer** - Time controls (5+0, 10+0, etc.) - select when creating challenge
- [ ] **PGN export** - Copy game notation to clipboard
- [ ] **Piece animation** - Smooth movement instead of instant snap
- [ ] **Draw by repetition** - Auto-detect threefold repetition
- [ ] **50-move rule** - Auto-detect draw by 50 moves without pawn move or capture
- [ ] **Insufficient material** - Auto-detect when checkmate is impossible (K vs K, etc.)

## Larger Features
- [ ] **Premoves** - Queue a move before your turn
- [ ] **Takebacks** - Request to undo a move (opponent must accept)
- [ ] **Player ratings/ELO** - Track skill over time, store in player profile
- [ ] **Game analysis** - Review with engine suggestions
- [ ] **Tournament mode** - Bracket-style tournaments in lobby

## UI Polish
- [ ] **Keyboard shortcuts** - Arrow keys for move navigation (already partial)
- [ ] **Mobile responsive** - Better touch support and layout
- [ ] **Themes** - Dark/light mode, piece set options
- [ ] **Confetti/celebration** - Victory animation
